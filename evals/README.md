# Evals

`evals.json` 是 skill 的回归题库：每条用例 = 输入 prompt + 期望行为 + 可勾选的断言。

## 三类用例

- **should_trigger**：该触发时必须触发（出现四段式判词或明确进入交付判卷）。
- **should_not_trigger**：不该触发时必须忍住（不出现条款编号、不主动判卷）。
- **behavior**：触发后的纪律（证据不足不硬判、用户否决走立法、复判不放行新问题等）。

## 怎么跑

```bash
python scripts/run_evals.py --check   # 校验题库
python scripts/run_evals.py --sheet   # 生成 evals/run_sheet.md
python scripts/run_evals.py --run     # 已装 Claude CLI 时自动跑
```

没有 CLI 时用跑表人工跑：

1. **每条用例单独开一个全新会话**。skill 在会话启动时加载；连续跑时，前一条已经激活 skill，后面的触发测试会被"预热"，只能算宽松通过。
2. prompt 原样粘贴，不要提示"用审丑 skill"。
3. 只看断言，不看措辞是否漂亮。
4. 结果填进跑表；失败项写一句原因。

## 判定口径

- 触发类：出现条款编号 / 四段式判词 / "交付模式"声明 = 触发；草稿与生成任务里出现这些 = 误触发。
- 行为类：逐条对断言勾选；边界情况（证据不足、否决、复判）以"有没有守住纪律"为准，不看输出长短。
