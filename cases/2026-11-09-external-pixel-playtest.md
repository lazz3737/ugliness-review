# 案例 004 · 外部试跑：像素版首屏

- **日期**：2026-11-09
- **类型**：外部试跑（由另一个会话按已安装的 skill 执行）
- **产物类型与域**：像素风小游戏首屏 `pixel_v4.png`（1440×900）· A/B/C 域
- **执行方式**：另一会话按 skill 流程走：先判模式 → 跑 `evidence.py` 采集证据（剪影墙 / 64px 缩略 / 迷眼 / 主色）→ 逐条判卷。
- **结果**：红线违规 9 条（A×4、C×1、B×4）、存疑 5 条、通过 6 条、未检 7 条；结论按演练口径“不许交付”。
- **纪律表现**：第一步就拦住了“这是草稿还是交付”的问题；证据先行；拿不准进存疑；没有一句审美判断。工具直接抓出两处肉眼容易漏的问题——64px 缩略下主角不可辨、迷眼图第一落点是右上白卡（一屏二主）。
- **暴露的缺口**：
  1. 没有像素画专档，A-R3「材质语言」只能硬套；
  2. 像素画的“材质”概念不适用，条款里没有写明替换关系。
- **归因**：条款错——域覆盖缺口，且适用前提没有显式写出。
- **修订动作**：新增 H 域《像素画》（v1.1.0，8 R + 2 T）；A-R3 增加“像素画项目改用 H-R3 描边 + H-R4 色板”的替换说明；参数槽补像素画参数（PPU / 色板 / 描边策略 / 字库 / 帧率）。
- **教训**：外部试跑暴露的缺口比自审真实；条款要写清“什么条件下不适用”，而不是默认所有项目同一套。
