# 项目参数槽

> 条款是通用判据；参数是项目自己的尺子。
> 判卷前先找项目参数；找不到就用默认值，并在报告开头声明"参数来源：默认值"。

## 需要项目提供的参数

### 1. 度量表

- 基准：角色全高 = 1.0（或项目自定义基准）。
- 至少覆盖：角色、常用道具（餐具/家具/食物）、场景构件（桌/椅/门/窗）。
- 格式示例：

| 对象 | 尺寸（角色 = 1.0） |
| --- | --- |
| 碗口宽 | 0.10~0.14 |
| 杯高 | 0.09 |
| 椅面高 | 0.24 |
| 桌面高 | 0.38 |
| 矮桌面高 | 0.22~0.28 |

### 2. 色卡

- 60-30-10 三段各给 2~3 个色值。
- 指定唯一的"信号色"及其使用场景。
- UI 与场景共用同一张卡。

### 3. 字号档位

- 3~4 档，级差 ≥1.4×（示例：32 / 22 / 15 / 12）。
- 标注每档用途（标题 / 副题 / 正文 / 元信息）。

### 4. 材质档位

- 3~4 档（示例：哑光布 / 木蜡 / 釉面 / 食物湿润）。
- 每档给：roughness 区间、高光锐度、颗粒密度。
- 指定"基准件三件套"：每个档位各一件已验收资产，供并排比对。

### 5. 网格与边距

- 网格单位（示例：8pt）。
- 固定边距档（示例：8 / 16 / 24 / 32）。
- 卡片内边距最小值。

### 6. 最小观看尺寸

- 项目声明的最小观看尺寸（示例：64px 图标 / 390px 宽手机屏）。
- 用于剪影与缩略验收。

### 7. 角色与动画参数

- 角色规格卡：头身比、四肢比例、手型（有指 / 圆手）、面数上限、脸与头发的实现方式。
- 关键点距离：嘴、手、道具、座椅之间的实测距离（判 C-R5 解剖可达性用）。
- 道具吸附点：手中心与道具沿 / 握把的相对位置。
- 帧率与关键 pose 保持帧数（示例：24fps，停 4~6 帧）。
- 过冲幅度（示例：95% → 102% → 100%）。
- 待机微动作层数与各自周期（呼吸 / 重心 / 视线）。

## 使用规则

- 项目参数优先于条款默认值；两者冲突时以项目参数为准，并在报告中注明。
- 参数缺失时不要自己编：用默认值 + 声明，或先问用户。
- 参数变更视为"改需求"，必须显式声明，并说明之前的判卷是否受影响。
