# 条款域 · G 视频与动效

> 只回答“什么算不及格”，不回答“什么值得拍”。
> 分档：**R = 红线**（命中必返工）；**T = 倾向**（可商量，下不为例要记账）。
> 参数：平台画幅、时长档、字幕字号、动效时长档由项目提供（见 `project-params.md`）。
> 判卷对象：**关键帧抽帧板 + 全片播放 + 字幕稿**；UI 动效另看录屏抽帧。

## G-R1 动效必须有动机

- **条款**：每个动效都要回答“它表达了什么”：反馈（我点了）、引导（看这里）、关系（从哪来 / 到哪去）、状态（加载中 / 完成）。答不出的动效一律删除。
- **为什么**：装饰动画不携带信息，只消耗注意力和性能；观众记住的是“花哨”，不是内容。
- **违反的样子**：满屏入场瀑布；悬停发光扫光；循环漂浮的装饰元素。
- **修法**：逐个动效标注动机，无动机的删；留下的按“反馈 > 引导 > 关系 > 状态”排优先级。
- **出处**：[[UI 动效设计]]（动效回答用户动作或状态变化）；Material motion 原则。

## G-R2 参数克制（时长、距离、曲线）

- **条款**：微交互时长分档：悬停进入约 140ms、离开约 200ms、按下约 90ms、面板切换约 200ms；位移要小（卡片抬起 2~4px、按钮按下 1px + 轻微缩放）；曲线按场景选（标准 / 减速 / 加速），禁止默认 linear；过冲幅度克制，弹簧不能变弹簧床。
- **为什么**：动效的“高级”来自参数克制，不是技术复杂。20px 位移、1.1 倍缩放、夸张 bounce 是廉价感的三大来源。
- **违反的样子**：所有元素 500ms 匀速平移 20px；按钮按下去弹三下；页面切换像果冻。
- **修法**：定一套时长与曲线 token（全站 ≤6 个值）；位移控制在个位数像素；弹簧幅度写进项目参数。
- **出处**：[[UI 动效设计]]（tasteskill 参数：140/200/90ms、2px、1.02~1.03）；Material easing。

## G-R3 编排（一个主角动作）

- **条款**：一屏只安排一个主角动作：要么入场错峰浮现（间隔 30~80ms，有逻辑顺序），要么点击时指示器滑到目标、面板跟随；其余元素全静。不许每张卡都 fade-up。
- **为什么**：多个同权重动画 = 没有主角 = 观众看不过来；“全场 fade-up”是模板指纹。
- **违反的样子**：每个 section 独立 fade-up；列表项逐个飞入但没有顺序逻辑。
- **修法**：挑一个“记忆时刻”，其余静默；错峰间隔按阅读顺序，不按网格顺序。
- **出处**：frontend-design（one orchestrated moment）；[[UI 动效设计]] 编排节。

## G-R4 可访问与性能

- **条款**：尊重 `prefers-reduced-motion` 并提供无动画替代；只动 transform / opacity；键盘操作与悬停效果等效可达、focus 可见；自动循环动画只用于特定技术感场景。
- **为什么**：前庭敏感用户会因动效不适；动布局属性会掉帧。可访问性是及格线。
- **违反的样子**：页面加载即自动播放循环背景动画；hover 才出现的关键操作；动画改 height 导致卡顿。
- **修法**：加 media query 降级；改用 transform；给键盘用户同等反馈。
- **出处**：WCAG 2.3（动画）；[[UI 动效设计]] 性能与可访问原则。

## G-R5 视频开头（前 3 秒）

- **条款**：前 3 秒给出主题与钩子：观众要知道“这是什么、为什么要看下去”。不许用 logo 动画、黑场、片头包装开场。
- **为什么**：短视频与演示的前 3 秒决定去留；片头动画是“自我感动”，观众不等。
- **违反的样子**：4 秒 logo 演绎开场；前 10 秒空镜；第一句话是“大家好，今天给大家介绍……”。
- **修法**：把最有信息量的一帧 / 一句话放第一秒；logo 放结尾或角落；片头包装删掉。
- **出处**：短视频节奏实践；演示开场研究。

## G-R6 节奏与剪辑

- **条款**：每 3~5 秒要有信息变化（画面、文字、声音至少一项）；删除空转镜头与重复信息；转场服务叙事，同类转场全片统一；不许用花哨转场掩盖剪辑问题。
- **为什么**：节奏是注意力的呼吸；没有信息变化的镜头，观众就开始划走。
- **违反的样子**：30 秒片子里 10 秒是走路空镜；每切一次换一种转场；转场比内容还抢眼。
- **修法**：时间轴上标注信息点，间隔超过 5 秒的段落砍或加速；转场只留 1~2 种。
- **出处**：剪辑节奏实践；短视频完播率研究。

## G-R7 字幕与安全区

- **条款**：字幕每行 ≤16 个汉字、最多两行；停留 ≥1.5 秒；字号不低于平台下限；位置避开画面主体与平台 UI 安全区；错别字零容忍；中英混排按 D 域。
- **为什么**：字幕是无声观看的唯一信息通道；一行 30 字没人读得完，压主体等于没字幕。
- **违反的样子**：一行 28 字；字幕压在人物脸上；被平台点赞栏遮住；“的地得”混用。
- **修法**：字幕稿先过 `scripts/copy_lint.py`；用安全区参考线检查（`scripts/evidence.py grid`）；按语义断行，不按字数硬断。
- **出处**：平台字幕规范；无障碍字幕指南；D-R5。

## G-R8 音画同步

- **条款**：口型、动作、音效必须同帧或误差 ≤1~2 帧；BGM 不压人声（人声出现时 ducking）；关键音效卡在动作峰值。
- **为什么**：音画差半拍，观众说不出哪里不对，但会统一感觉“廉价”。
- **违反的样子**：关门声比画面晚半秒；BGM 盖过解说；节奏点全部错开。
- **修法**：抽帧对齐音效峰值；人声轨单独混音；导出前戴耳机整片过一遍。
- **出处**：影视剪辑实践；短视频混音惯例。

## G-R9 抽帧可读（单帧成立）

- **条款**：关键帧单独截图也要成立：主体清晰、构图完整、剪影可读；至少一张帧可以当封面；不依赖“动起来才看得懂”。
- **为什么**：封面、缩略图、暂停画面都是单帧；单帧糊掉，传播就断了。
- **违反的样子**：全片没有一张能当封面的帧；暂停时主体正好在运动模糊里。
- **修法**：全片抽帧做墙（见取证）；挑 3 张候选封面；主体运动模糊过大的镜头重拍或换帧。
- **出处**：A-R7 / C-R2 的可读性原则在视频域的延伸。

## G-R10 素材与版权

- **条款**：画面、音乐、字体、肖像必须有授权或为自制；AI 生成素材按项目要求标注；不盗用影视片段、商用字体与未授权音乐；商标与人物肖像合规。
- **为什么**：版权问题在发布后才会爆炸；一条侵权投诉能让整个账号停摆。
- **违反的样子**：随手下载的 BGM；未授权商用字体；影视片段搬运；AI 生成的人脸未标注。
- **修法**：建素材来源表（URL / 授权类型 / 期限）；发布前逐项核对；不确定的换掉。
- **出处**：平台版权规范；商用素材授权实践。

## G-T1 风格统一（倾向）

- **条款**（倾向）：全片一套色调、一套字体、一套字幕样式、1~2 种转场；任意两段并排像同一支片子。
- **修法**：先定 LUT 与字幕模板；批量套用。
- **出处**：视觉一致性原则（B-R9 / F-R6 的延伸）。

## G-T2 导出规格（倾向）

- **条款**（倾向）：按平台导出：分辨率、帧率、码率、封面、画幅（竖屏 / 横屏）符合目标平台要求；同一内容多平台分发时分别导出，不拉伸。
- **修法**：建导出预设；发布前对照平台规格表。
- **出处**：平台上传规范。

## 取证与判卷

- **抽帧板**：`ffmpeg -i in.mp4 -vf fps=1/2 frames/%03d.png`（每 2 秒一帧；需安装 ffmpeg：`winget install ffmpeg`），再 `scripts/evidence.py thumbs frames/ --size 240` 拼墙，查 G-R6 / G-R9。
- **剪影墙**：关键帧过 `scripts/evidence.py silhouette`，查构图与主体可读（G-R9）。
- **安全区**：字幕帧叠 `scripts/evidence.py grid`，查平台 UI 遮挡（G-R7）。
- **字幕稿**：`scripts/copy_lint.py 字幕.srt`，查标点、句长、错别字（G-R7 / D-R5）。
- **音画同步**：抽动作峰值前后各 2 帧，与音频波形对照（G-R8）。
- **播放测试**：静音看一遍（字幕是否自足），戴耳机看一遍（混音是否清楚）。

## 判卷样例（匿名化）

> 某 30 秒产品短片，首轮判卷节选。

**【G-R5 视频开头】【违规】**
证据：0~4 秒为 logo 演绎动画，第 5 秒才出现产品画面；静音观看时前 4 秒无任何信息。
修法：把产品使用画面提到第 1 秒；logo 移到结尾角标。

**【G-R7 字幕与安全区】【违规】**
证据：第 12 秒字幕单行 28 字；第 18 秒字幕被底部平台操作栏遮住约 1/3。
修法：按语义断行至每行 ≤16 字；字幕整体上移进安全区。

**【G-R8 音画同步】【违规】**
证据：关门画面在第 8 秒第 3 帧，关门音效在第 8 秒第 16 帧，相差约半秒。
修法：音效轨前移对齐动作峰值；复判逐帧核对。

**【G-R6 节奏与剪辑】【存疑】**
证据：第 20~27 秒为单一空镜，无信息变化；转场用了三种类型。
修法：空镜压缩到 3 秒或删除；转场统一为一种后复判。

**结论**：红线 3 条未清零，不许发布。
