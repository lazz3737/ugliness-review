# 条款域 · B UI 与版式

> 只回答"什么算不及格"，不回答"什么值得做"。
> 分档：**R = 红线**（命中必返工）；**T = 倾向**（可商量，下不为例要记账）。
> 字号、颜色、字体家族的具体值由项目参数提供；本文给默认示例。

## B-R1 一屏一主

- **条款**：每一屏只能有一个"最大声"的元素（主标题 / 主按钮 / 主图三选一）。其余元素音量必须明显小于它。
- **为什么**：没有焦点 = 没有判断 = 没有信任。用户 0.5 秒内要知道"看哪里、做什么"。
- **违反的样子**：四枚等大胶囊 + 卡片 + 两个等大按钮同时在场；弹层里标题和按钮一样大。
- **修法**：每个界面标注"主元素"；截图缩到 25% 看第一眼落点。
- **出处**：海报设计层级综述；CARP 原则。

## B-R2 字号 3~4 级、级差 ≥1.4×

- **条款**：全站只允许 3~4 个字号档位，相邻档位差距 ≥1.4 倍（默认示例 32/22/15/12）。不许出现"16 与 15 与 14"这种彼此彼此的字号。
- **为什么**：字号差不够 = 层级不存在；层级不存在 = 所有字一样重要 = 没有信息。
- **违反的样子**：14px、16px、15px、13px 四档挤在 3px 内。
- **修法**：定 type scale，所有界面只许用这几档。
- **出处**：海报排版指南；CJK 排版字号层级实践。

## B-R3 字体 ≤2 家族；图标不许用 emoji

- **条款**：一个界面最多两个字体家族：一个"说话体"（标题/刊名，可有性格）+ 一个"干活体"（正文/数字，必须清楚）。UI 图标必须自己画或统一风格，禁止 emoji 当图标。
- **为什么**：emoji 自带系统厂商风格，和你的世界一个字都对不上；它是"没设计"的告示牌。
- **违反的样子**：界面里出现 💬🍗🥣；全站只有一档系统字体，标题正文同一个声音。
- **修法**：定两个字体角色；图标做一套 16~24px 线性/面性图标。
- **出处**：海报排版指南；CJK 混排指南。

## B-R4 中文排版细则

- **条款**：中文正文行高 1.4~1.6；中西文之间留 1/4 空；中文标点全角；引号用「」或""，不许直引号混排；每行 ≤ 40 个汉字。
- **为什么**：中文的"贵"大半在字距行距里。行距挤 = 廉价感最快来源。
- **违反的样子**：行高默认 1.0 挤成一坨；「¥12·320kcal」无空格；中英标点随机混用。
- **修法**：写死行高 token；文案过一遍标点清洗。
- **出处**：CJK Typography & Mixed-Script Guide；中文撰稿规范。

## B-R5 网格与对齐

- **条款**：所有元素对齐到同一套网格/基线；正文左对齐；标题、正文、按钮共享左边线。屏幕元素不许"随手漂"。
- **为什么**：对齐是秩序感的物理来源；一个 3px 的漂移能被眼睛抓到并读成"不讲究"。
- **违反的样子**：底部按钮离屏幕边缘的距离与顶部胶囊不一致；卡片内文字与按钮左缘不对齐。
- **修法**：设 8pt 网格与固定边距档（8/16/24/32）；截图拉参考线验收。
- **出处**：Adobe 布局七原则；RPI/ND 海报视觉规范。

## B-R6 留白预算

- **条款**：屏幕边距 ≥5% 屏宽；板块间距 = 行距 × 2；卡片内边距 ≥ 字高 × 1.5。留白不是"没做完"，是设计。
- **违反的样子**：文字贴边；卡片内容挤满四角；元素之间距离随机。
- **修法**：按条款定 token；用像素尺量一遍。
- **出处**：海报设计指南（white space 与边距惯例）。

## B-R7 UI 色彩与世界同源

- **条款**：UI 的 60-30-10 与场景共用一张色卡：UI 底色、文字色、按钮色必须能指向世界里的某件东西。禁止 UI 自带一套色系。
- **为什么**：UI 是世界的"第七件家具"。两套色系并置 = 游戏像给截图套了个网页。
- **违反的样子**：场景奶油木色，按钮却是糖果粉 + 薄荷绿；弹层纯白 + 灰阴影，和房间毫无血缘。
- **修法**：色卡一次定义、场景与 UI 共用；按钮色从世界色里选。
- **出处**：60-30-10 与品牌色稀缺性经验。

## B-R8 廉价五件套

- **条款**：以下五项，命中 ≥2 项即返工：①彩虹/多色渐变；②又大又糊的投影；③描边字/发光字；④满屏等大圆角胶囊；⑤emoji 当图标。
- **为什么**：这五样是"默认模板"的指纹，单看都"可爱"，合起来就是"没人在管"。
- **修法**：逐项对照表；改动优先级从"减"开始，而不是从"加"。
- **出处**：UI 反模式合集；"AI 生成感"讨论中的高频特征。

## B-R9 版式语法统一（刊物感）

- **条款**：所有卡片/弹层/结算页共享同一套"版式语法"：刊名（固定位置）→ 标题 → 副题 → 元信息 → 内容 → 落款，位置与字号档位固定。任意两屏并排，必须像同一本刊物的两页。
- **为什么**：一致性是"被出版过"的观感来源；每屏一套排版 = 散页传单。
- **违反的样子**：三种弹层三种排版逻辑；图标位置各不相同。
- **修法**：做一页"版式母版"，全部界面从母版派生。
- **出处**：库主参考集（1999 海报的 STARRING 版式语法）；海报 anatomy 综述。

## B-T1 纸感与印刷材质（倾向）

- **条款**（倾向）：UI 材质与画风保持一致：若画面走印刷/绘本，UI 用同源的纸色、纤维、油墨感；若走清爽，UI 不许出现仿古纸。
- **修法**：与 A-R3 的材质档位对齐，UI 统一取一档。
- **出处**：精装书/印刷品参考集；A-R3 的延伸。
