# 条款域说明

每个域一个文件，文件名用小写连字符。新增域时照本说明办。

## 文件结构

1. **头部**：一句话说明本域覆盖什么；分档说明（R / T）；参数说明（哪些值可由项目覆盖）。
2. **条款**：每条按五段写——
   - **条款**：可判定的规则（判据）。
   - **为什么**：违反后观感上会发生什么。
   - **违反的样子**：一眼可查的实例（这是判卷时最常用的部分）。
   - **修法**：可执行的修复动作。
   - **出处**：公开资料或项目实践。
3. **编号**：`域字母-R序号`（红线）/ `域字母-T序号`（倾向）。**自 v1.0 起编号冻结**：不复用、不改号；弃用的条款标 `(deprecated)`，不删除。英文索引见 `index.en.md`。

## 现有域

- `art-scene-props.md` — A 域：道具与场景（比例、功能、材质、落地、细节预算、色彩、剪影、叙事、切线、疏密）
- `ui-layout.md` — B 域：UI 与版式（焦点、字号、字体与图标、中文排版、网格、留白、色彩同源、廉价五件套、版式语法、纸感）
- `character-animation.md` — C 域：角色与动画（规格卡、剪影、持具接触、形变、解剖可达性、弧线与节奏、挤压拉伸、脚部接触、循环与待机、穿模、表情视线、动作个性）
- `copywriting.md` — D 域：文案（说人话、一词一义、动作即结果、错误与空状态、中文标点、术语称谓、语气、不注水、扫读、事实纪律）
- `web-pages.md` — E 域：网页（首屏、一屏一节、响应式、状态覆盖、可访问性、触控目标、真实内容、稳定性、导航、表单、模板指纹）
- `slides-docs.md` — F 域：PPT 与文档版式（一页一断言、断言-证据、页密度、字号、图表纪律、母版、层级、事实、交付可用）
- `video-motion.md` — G 域：视频与动效（动机、参数、编排、可访问、开头、节奏、字幕、音画同步、抽帧可读、版权）
- `pixel-art.md` — H 域：像素画（整数缩放、像素密度、描边策略、色板容量、抗锯齿、像素字库、剪影对比、帧纪律）

## 更多域（欢迎贡献）

- 包装：货架可读性、信息层级、印刷规范。
- 舞台 / 现场：视线、动线、字幕与提示、事故冗余。
- 任何“缺陷可列举”的视觉交付。

## 新增域的最低要求

- 至少 5 条可判定的 R 条款，每条带“违反的样子”与修法。
- 至少 1 条能被现有取证工具箱（`evidence-kit.md`）验证的条款；工具箱不够用时，先补工具。
- 附 1 个真实（匿名化）判卷样例。
