# 取证工具箱

> 判据不等于证据。没有取证的判词会退化成"感觉不对"。
> 三条原则：用原生分辨率的图；前后对比用同一位置；每份证据写清"哪件、哪块、几倍"。

## 自动化

以下工具已并入 `scripts/`（离线、确定性）：

- `evidence.py kit` — 一条命令生成灰度、模糊、剪影、缩略墙、主色统计与 manifest。
- `evidence.py silhouette` / `thumbs` — 剪影墙与缩略墙。
- `evidence.py gray` / `blur` — 灰度与眯眼测试。
- `evidence.py crop` — 切线放大。
- `evidence.py colors` — 主色与饱和面积。
- `evidence.py grid` — 网格与边距参考线。
- `evidence.py contrast` — WCAG 对比度。
- `copy_lint.py` — 标点、直引号、省略号、空格、句长、黑名单。

用法见 `scripts/README.md`。手工工具（首眼测试、遮名识物、遮 logo、抽帧选点）仍需人来做。

## 工具箱

### 1. 原生截图

- **用途**：一切判卷的底图。
- **操作**：原生分辨率、设备实际观看尺寸；不要用聊天软件压缩过的图。
- **证据**：文件名 + 尺寸（如 `ui_current.png 1080×1920`）。

### 2. 首眼测试（1 秒 / 5 秒）

- **用途**：查焦点与层级。
- **操作**：把截图闪现 1 秒后问自己"先看到什么"；再给 5 秒，问"第二个看到什么"。
- **判什么**：第一落点不是主角 → A-R5 / B-R1 存疑；5 秒说不清是什么 → E-R1 存疑。
- **证据**：写下第一落点，不许事后改口。

### 3. 眯眼 / 高斯模糊

- **用途**：去掉细节看明度结构与落点。
- **操作**：眯眼，或 `python scripts/evidence.py blur <img>`。
- **判什么**：A-R5 细节预算、B-R1 一屏一主。
- **证据**：保留模糊图，圈出落点。

### 4. 灰度转换

- **用途**：排除色彩干扰，检查明度结构。
- **操作**：`python scripts/evidence.py gray <img>`。
- **判什么**：A-R6 色彩克制、A-R7 剪影。
- **证据**：灰度图与原图并排。

### 5. 剪影墙

- **用途**：检查形状可读性（资产与动作关键帧都适用）。
- **操作**：`python scripts/evidence.py silhouette <assets/> -o evidence`。
- **判什么**：A-R7 剪影、C-R2 关键姿态可读。1 秒认不出 → 违规。
- **证据**：剪影墙整图 + 可疑件单张。

### 6. 缩略墙

- **用途**：按真实观看尺寸验收。
- **操作**：`python scripts/evidence.py thumbs <assets/> --size 64`。
- **判什么**：A-R7 64px 可读；B 域图标与字号。
- **证据**：缩略墙 + 认不出的件名单。

### 7. 切线放大

- **用途**：排查轮廓相切、平行贴边。
- **操作**：`python scripts/evidence.py crop <img> --box x1,y1,x2,y2 --zoom 3`。
- **判什么**：A-R9 切线禁止。
- **证据**：3× 裁剪图，圈出相切段。

### 8. 遮名识物

- **用途**：检查形式是否服从功能。
- **操作**：遮住资产名字，2 秒内猜用途。
- **判什么**：A-R2 形随功能。
- **证据**：写下猜测结果；猜错即违规。

### 9. 取色器

- **用途**：量化色彩使用。
- **操作**：`python scripts/evidence.py colors <img> --top 8`。
- **判什么**：A-R6 色彩克制、B-R7 色彩同源。
- **证据**：主色表 + 饱和面积占比。

### 10. 网格与参考线

- **用途**：检查对齐与节奏。
- **操作**：`python scripts/evidence.py grid <img> --step 8 --margin 5`。
- **判什么**：B-R5 网格与对齐、B-R6 留白预算、E-R3 响应式边距。
- **证据**：带网格的截图，标出漂移像素。

### 11. 边距测量

- **用途**：量化留白。
- **操作**：用像素尺量边距、卡片内边距、按钮高度（或从 grid 图读数）。
- **判什么**：B-R6 留白预算、E-R6 触控目标。
- **证据**：测量值列表（如"卡片内边距 14px，字高 13px，应 ≥20px"）。

### 12. 对比度测量

- **用途**：检查文字与控件可读性。
- **操作**：`python scripts/evidence.py contrast <img> --fg x,y --bg x,y`。
- **判什么**：E-R5 可访问性下限（正文 ≥4.5:1，大字与非文本 ≥3:1）。
- **证据**：色值 + 对比度数值。

### 13. 并排基准件

- **用途**：检查材质语言是否统一。
- **操作**：把新资产与项目"基准件三件套"并排，同机位、同光。
- **判什么**：A-R3 材质语言。
- **证据**：并排图；差异写在高光、粗糙度、颗粒、色彩响应四项里。

### 14. 遮 logo / 换名测试

- **用途**：检查版式语法是否统一。
- **操作**：遮住 logo 与刊名，看两屏并排是否像同一本刊物。
- **判什么**：B-R9 版式语法统一、E-T2 视觉与文案同源。
- **证据**：两屏并排图。

### 15. 文案清洗

- **用途**：检查标点、空格与模板词。
- **操作**：`python scripts/copy_lint.py <文件或目录>`。
- **判什么**：D-R5 中文标点、D-R8 黑名单、D-T1 句长。
- **证据**：lint 输出（行号 + 列号 + 原文片段）。

### 16. 动作抽帧

- **用途**：检查运动节奏、关键姿态与循环。
- **操作**：导出关键帧（起 / 蓄 / 发 / 收），一个动作至少 6 格，拼成一张板；循环动作加首尾帧并排。
- **判什么**：C-R2 剪影、C-R6 弧线、C-R7 节奏、C-R8 挤压拉伸、C-R10 循环。
- **证据**：抽帧板 + 关键帧编号与时间戳。

### 17. 网页状态走查

- **用途**：检查交互状态与响应式。
- **操作**：三档宽度（390 / 768 / 1440）各截一张；每个组件截默认 / hover / focus / disabled；数据区截 loading / empty / error。
- **判什么**：E-R3 响应式、E-R4 状态覆盖、E-R9 导航。
- **证据**：状态矩阵拼图 + 断点截图。

## 证据留存规范

- 所有证据放项目内 `evidence/` 目录，按批次/资产命名。
- 报告引用相对路径；同一问题只留最能说明问题的一张。
- 公开示例必须匿名化：项目名、角色、剧情、商业信息一律替换。

## 证据不足时

- 只有低清截图、只有聊天预览图、只有局部、没有关键帧 → 不判，标"未检"并说明需要什么（原生截图 / 原图 / 指定机位 / 关键帧导出 / 三档截图）。
- 不许用"看起来像"代替证据。
